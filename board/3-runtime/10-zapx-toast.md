# A toast in zapx.ui

zapx.ui (std/zapx/ui) has the components but the toast, which needs a script: a `Toaster` placed
once in the page and a call that shows a message for a few seconds (Sonner's look: bottom right,
stacked, a title and a description). zaplink's page uses it when an order, a setting or a new
agent is sent.
