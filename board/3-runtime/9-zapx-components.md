# zapx components, in the manner of shadcn/ui

A library of components in std/zapx (button, input, select, checkbox, card, badge, tabs, dialog,
table, toast), each a function returning a Node with its classes and one stylesheet of tokens
(colors, radius, spacing, dark and light), so a page looks finished without its own CSS. Then
zaplink's page rebuilt on them.
